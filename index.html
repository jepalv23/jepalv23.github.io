About the Lab

I've been working in software engineering for more than 10 years, primarily building software, services, APIs, automation, and infrastructure that support production systems.

This home lab is a place to work closer to the infrastructure layer: building virtualized environments, experimenting with networking, deploying services, automating infrastructure, and learning how systems behave outside of a typical development environment.

The goal isn't to recreate a production data center at home. It's to have a flexible environment where I can break things, rebuild them, automate them, and understand them.

Goals

Infrastructure

Build and maintain a small, reliable virtualization environment for running services, development environments, and experiments.

Automation

Reduce manual configuration through infrastructure as code, configuration management, CI/CD, and repeatable deployments.

Networking

Learn more about VLANs, routing, DNS, firewalls, reverse proxies, segmentation, and operating services across multiple networks.

Observability

Build practical monitoring and logging around the services running in the lab and understand how systems behave over time.

Distributed Systems

Experiment with databases, message queues, service discovery, caching, clustering, and other distributed system patterns.

Learning by Building

Use the lab to explore technologies that are difficult to understand completely without actually operating them.

Lab Philosophy

Everything in the lab should be reproducible where practical. Configuration belongs in source control, infrastructure should be automated, and services should be treated as disposable rather than permanent snowflakes.

The lab is intentionally experimental. Some projects will succeed, some will be rebuilt from scratch, and some will probably be removed entirely. That's part of the point.
